# If-Else & Exception Handling

Practice exercises focused on conditional logic (if-elif-else) and
exception handling in Python.

## Exercises

- number_classification.py — Classifies a user-input number as
  positive, negative, or zero.
- temperature_status.py — Takes a temperature value and reports
  its status (Freezing, Cold, Cool, Warm, or Hot).
- bmi_calculator.py — Calculates Body Mass Index (BMI) from
  user-input height and weight, using ExceptionGroup to report
  multiple validation errors (invalid weight and/or height) at once.

Each script includes basic input validation using try/except to
handle invalid user input.
