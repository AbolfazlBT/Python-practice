# Loops & Functions

Practice exercises focused on for/while loops and function
definitions in Python, each solved using multiple approaches to
compare readability and style.

## Structure

- prime_numbers/ — Finding, summing, and counting prime numbers.
  - prime_matrix.py — Finds primes up to a limit and groups them
    into rows of three.
  - prime_sum.py — Sums primes up to a limit, using a flag
    variable and a flag-free approach.
  - prime_counter.py — Counts and lists primes up to a limit,
    using a helper function.
- digit_operations/ — Working with the individual digits of a number.
  - reverse_number.py — Reverses a number's digits, iteratively
    and recursively.
  - sum_of_digits.py — Sums a number's digits, using a loop, a
    generator expression, and recursion.
- string_processing/ — Text-based exercises.
  - vowel_counter.py — Counts vowels in text, four different ways.
  - remove_vowels.py — Removes vowels from text, two different ways.
  - reverse_string.py — Reverses a string (or a signed number as
    a string), using slicing and reversed().
- list_processing/ — Validating and analyzing lists of numbers.
  - string_to_int_converter.py — Converts a list of strings to
    integers, separating valid numbers from invalid entries.
  - target_number_counter.py — Counts how many times each target
    number appears in a list.

Each script includes input validation with try/except to handle
invalid user input.
